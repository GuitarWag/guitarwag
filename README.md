## What I work on

- **AI & LLM integrations** — RAG systems and agent orchestration with LangChain & LangGraph, Vertex AI, Gemini, and the Anthropic Claude API, backed by Neo4j and Qdrant.
- **Software engineering** — Go microservices on Kubernetes, Node.js and Python backends, React / Next.js / React Native on the frontend, TypeScript across the stack.
- **Cloud & DevOps** — multi-cloud on GCP and AWS, infrastructure as code with Terraform, CI/CD with Cloud Build, and a focus on reliability, cost, and observability.
